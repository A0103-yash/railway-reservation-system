# Railway Reservation System

A beginner Python project that simulates a basic railway reservation system.

## Features
- Ticket booking
- Source and destination selection
- Train information lookup
- Reservation checking

## Version

### v1.0
- Basic railway reservation program
- Booking through user input
- Passenger details checking
- Train information display

### v1.1
- Added Passenger details
- Age verfication
- Added Random train number and timings

## Future Updates
- Multiple Passenger details
- PNR generation
- Seat management
- File handling
